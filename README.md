## Overview

This repository serves as a practical review of deep learning and machine learning concepts. To make the learning process more engaging, the project focuses on Speech-to-Text (STT) technology. The primary goal is to build a Vietnamese STT system entirely from scratch utilizing the PyTorch framework.
